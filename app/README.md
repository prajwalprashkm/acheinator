# Acheinator (web app)

Project overview, architecture, results, and sources: **[../README.md](../README.md)**.

## Local development

```bash
npm ci
npm run animations   # optional: refresh public/character/ from ../animations/symptomator
npm run dev
```

```bash
npm test
npm run build        # static export to out/
```

Model assets live in `public/model/` (generated by `../training/export_web_assets.py`).
